02 — Courses

ふたつのコース

年齢と目的に合わせた、ふたつのクラス。どちらも定員6名の少人数制です。

初心者〜

基礎デッサンコース

Foundation Drawing Class

鉛筆の削り方、線の引き方から。立方体や球などの基本形態、静物、石膏像へと段階的に進みます。初めての方も、趣味でじっくり学びたい方も歓迎です。

  • 道具の使い方と基本の線から丁寧に
  • 形のとらえ方・光と陰影・質感表現を基礎から
  • 毎回の講評で上達のポイントを確認

美術系高校・美大受験

受験デッサンコース

Exam Drawing Class

志望校の出題傾向に合わせた課題演習。時間を計った実戦形式と、毎回の講評で合格レベルの描写力を鍛えます。ポートフォリオ指導にも対応します。

  • 志望校別の課題と時間を計った実戦演習
  • 構図・プロポーション・描き込みの徹底強化
  • ポートフォリオ・実技面接の対策にも対応
